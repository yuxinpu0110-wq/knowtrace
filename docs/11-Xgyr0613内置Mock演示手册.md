# Xgyr0613 内置 Mock 演示手册

本手册用于评审现场演示 KnowTrace。Xgyr0613 账号内置了三个相互独立的 Mock 场景：线性代数、微积分、军事理论。Mock 会根据当前知识图谱自动切换，演示时不需要 API Key，也不会调用外部模型。

## 一、演示前准备

1. 打开 `http://127.0.0.1:5173/`。
2. 在登录页点击快捷登录用户 **Xgyr0613**。
3. 确认顶部的 **内置 Mock** 已开启。若未开启，点击一次将其打开。
4. 点击首页的 **当前知识图谱：图谱名**，进入知识图谱管理页。
5. 点击图谱名称切换图谱。切换后会继续停留在管理页，便于连续查看；点击左上角 **返回** 才回到首页。

> 演示问题请尽量完整复制本手册中的文字。数学公式使用 `$...$` 包裹，页面会以 LaTeX 形式显示。

## 二、推荐的完整演示路线

如果现场只有 5～7 分钟，建议完整演示“微积分”，再快速切换到“线性代数”和“军事理论”，分别提交一次问题，证明三个图谱拥有独立内容。

完整流程如下：

1. 选择知识图谱。
2. 提交本手册给出的推荐问题。
3. 先展示系统给出的直接回答，强调“用户先得到答案，再自主选择是否诊断”。
4. 点击 **开始诊断**。
5. 完成三轮诊断，观察候选薄弱节点的橙色深度、光晕范围以及图谱的缩放定位随置信度更新。
6. 诊断完成后，点击图谱中被标记为橙色的主要薄弱节点进入学习。
7. 学习时先点击一次 **没看懂**，展示更通俗的附加解释；随后点击 **理解了，继续** 推进学习。
8. 完成最后的五选一检验题。答对后观察橙色薄弱光逐渐熄灭，再平滑变为绿色掌握状态。

为了最清楚地表现诊断置信度逐轮增强，三轮诊断推荐按以下方式操作：

- 第 1 题点击 **模糊**。
- 第 2 题点击 **不会**。
- 第 3 题选择正确选项 **A**。

Mock 的候选薄弱点置信度会逐轮上升，最终主要薄弱点约为 92%。

## 三、微积分演示剧本（最推荐）

### 提问

切换到 **微积分**，输入：

```text
如何用连续的定义说明函数 $\sin x$ 在 $x=0$ 处连续？
```

预期效果：

- 蓝色定位节点为“函数的连续性”。
- 系统先直接说明：因为 $\lim_{x\to0}\sin x=0=\sin0$，所以函数在 $x=0$ 处连续。
- 点击 **开始诊断** 后，候选薄弱点包含“连续的定义”，而不是跳到无关知识点。

### 诊断

1. “函数 $f(x)$ 在 $x=a$ 连续，最核心的等式是什么？”
   - 正确答案 A：$\lim_{x\to a}f(x)=f(a)$
   - 演示操作：点击 **模糊**。
2. “判断一点连续时，除了极限存在，还必须检查什么？”
   - 正确答案 A：$f(a)$ 有定义且等于该极限
   - 演示操作：点击 **不会**。
3. “$\lim_{x\to0}\sin x$ 与 $\sin0$ 分别等于多少？”
   - 正确答案 A：二者都等于 $0$
   - 演示操作：选择 **A**。

诊断完成后，点击主要橙色薄弱节点 **连续的定义**。

### 学习与检验

- 第一屏可点击一次 **没看懂**，展示通俗解释分支。
- 之后持续点击 **理解了，继续**，依次浏览定义、直觉、关系、例子和易错点。
- 最终检验题：“若 $\lim_{x\to2}f(x)=3$ 且 $f(2)=3$，可以得到什么结论？”
- 选择 **A：函数在 $x=2$ 连续**。

答对后，应看到“连续的定义”先褪去橙色，再逐渐点亮为绿色。

## 四、线性代数演示剧本

### 提问

切换到 **线性代数**，输入：

```text
用高斯消元法解含参数的线性方程组时，为什么会出现无穷多组解？
```

预期效果：

- 蓝色定位节点为“高斯消元法”。
- 系统先说明：相容方程组中，如果矩阵秩 $r$ 小于未知数个数 $n$，就有 $n-r$ 个自由变量，因此产生无穷多组解。
- 主要薄弱点最终定位为“主元与自由变量”。

### 诊断

1. “在行最简阶梯形中，没有对应主元的未知量称为什么？”
   - 正确答案 A：自由变量
   - 演示操作：点击 **模糊**。
2. “相容方程组有 $n$ 个未知数、矩阵秩为 $r$，自由变量通常有几个？”
   - 正确答案 A：$n-r$ 个
   - 演示操作：点击 **不会**。
3. “当至少存在一个自由变量时，它为何通常带来无穷多组解？”
   - 正确答案 A：自由变量可连续取不同值，并相应确定主元变量
   - 演示操作：选择 **A**。

诊断完成后，点击主要橙色薄弱节点 **主元与自由变量**。

### 学习与检验

- 可先点击一次 **没看懂**，再用 **理解了，继续** 完成学习。
- 最终检验题：“相容线性方程组有 $5$ 个未知数，系数矩阵的秩为 $3$。自由变量有几个？”
- 选择 **C：$2$**。

如果想展示答错分支，可先选择 B：$1$。页面会提供继续学习或退出学习；正式演示为节省时间，建议直接选择 C。

## 五、军事理论演示剧本

### 提问

切换到 **军事理论**，输入：

```text
信息化战争的制胜要素包括什么？
```

预期效果：

- 蓝色定位节点为“信息化战争的制胜要素”。
- 系统先回答信息优势、体系优势、决策优势和精确作战能力，并说明侦察、指挥、通信与火力平台的体系融合。
- 主要薄弱点最终定位为“信息化战争的基本特征”。

### 诊断

1. “信息化战争中，争夺并保持哪一种优势通常是取得主动权的前提？”
   - 正确答案 A：信息优势
   - 演示操作：点击 **模糊**。
2. “为什么信息化战争强调体系对抗，而不只是单件武器性能？”
   - 正确答案 A：作战效能来自侦察、指挥、通信和火力等系统协同
   - 演示操作：点击 **不会**。
3. “缩短‘发现—判断—决策—行动’链路，主要形成什么优势？”
   - 正确答案 A：决策与行动速度优势
   - 演示操作：选择 **A**。

诊断完成后，点击主要橙色薄弱节点 **信息化战争的基本特征**。

### 学习与检验

- 可先点击一次 **没看懂**，再点击 **理解了，继续**。
- 最终检验题：“下列哪项最能体现信息化战争的核心制胜逻辑？”
- 选择 **A：夺取信息优势并形成体系协同**。

## 六、重复彩排时的状态处理

学习检验通过后，节点会保持绿色“已掌握”状态。如果要重复彩排同一个完整场景：

1. 进入 **管理知识图谱**。
2. 点击对应图谱名称右侧的 **…** 进入编辑。
3. 找到本手册标出的主要薄弱节点，把状态改回普通状态；“薄弱”和“已掌握”互斥，不要同时选择。
4. 点击右下角 **保存**，系统会返回知识图谱管理页。

三个需要复位的节点分别是：

- 微积分：连续的定义
- 线性代数：主元与自由变量
- 军事理论：信息化战争的基本特征

## 七、现场讲解重点

- “系统不是只给答案，而是先解答当前问题，再由用户决定是否追踪知识漏洞。”
- “蓝色表示问题直接关联的知识点；进入诊断后普通节点平滑熄灭，橙色表示候选薄弱点。”
- “橙色越深、光晕越大，代表薄弱置信度越高；每答一道诊断题，图谱都会重新定位并更新置信度。”
- “学习并不是一次性阅读。用户可以反复点击‘没看懂’获得更通俗的解释，连续三次仍不理解时也可以退出，薄弱状态会保留。”
- “通过五选一检验后，橙色先逐渐消退，再逐渐转为绿色，表示真正掌握。”
- “三个知识图谱使用独立 Mock 内容，说明同一套学习闭环可以迁移到不同学科。”

## 八、异常排查

- 问题被判定为超纲：确认当前图谱与问题所属学科一致，并完整使用本手册的问题。
- 内容与图谱不一致：回到管理知识图谱，重新点击正确图谱名称，再点击返回。
- 页面提示未配置 API：确认顶部 **内置 Mock** 已开启；Mock 模式不需要 API Key。
- 节点已经是绿色：按照“重复彩排时的状态处理”把目标节点改回普通状态。
