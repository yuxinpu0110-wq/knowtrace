# KnowTrace 视觉设计规范

> 适用范围：KnowTrace 产品界面、项目路演 PPT、海报延展与演示视频。  
> 核心目标：像 Apple 产品页面一样简洁、克制、有呼吸感；保留“知溯”海报的墨蓝、雾蓝、橙色与绿色品牌识别。

## 1. 品牌核心

### 1.1 一句话定位

**不急着问答案，先找到你卡住的地方。**

KnowTrace 不是直接给出答案的解题工具，而是从一个具体问题出发，沿知识图谱向前追溯，定位用户真正缺失的前置知识。

### 1.2 视觉关键词

- 清晰：一屏只表达一个核心观点。
- 克制：避免复杂背景、渐变堆叠和多余装饰。
- 精准：用节点、路径和逐渐增强的高亮表达“定位过程”。
- 温和：整体为低饱和浅色，橙色只用于知识断点和重点提示。
- 有呼吸感：大留白、少边框、短文案、明确层级。

### 1.3 不建议使用

- 深色科技风、霓虹光效和赛博朋克配色。
- 大面积橙色或绿色背景。
- 复杂纹理、山形插画、纸张纹理等装饰性背景。
- 每个元素都加阴影、描边或动画。
- 一页 PPT 同时放置多个同等重要的结论。

## 2. 品牌色板

| 用途 | 色彩名称 | HEX | 使用建议 |
| --- | --- | --- | --- |
| 主文字 / 品牌标题 | 墨蓝 | `#0B2543` | 标题、重点数字、深色主按钮 |
| 正文 | 深雾蓝 | `#102D4E` | 正文、图谱标签 |
| 主交互色 | 路径蓝 | `#287ACC` | 链接、选中态、问题相关节点 |
| 浅蓝底 | 雾蓝 | `#E9F3FC` | 图标底、选中背景、轻提示 |
| 知识断点 | 定位橙 | `#F0642B` | 薄弱节点、关键结论、少量强调 |
| 橙色浅底 | 暖雾橙 | `#FFF1EA` | 超纲提示、薄弱点信息卡 |
| 已掌握 | 山径绿 | `#2FA36B` | 已掌握节点、成功状态 |
| 绿色浅底 | 浅叶绿 | `#EAF7F0` | 成功卡片、完成状态 |
| 页面底色 | 冷白 | `#F7F9FB` | 应用背景或 PPT 浅灰分区 |
| 卡片底色 | 纯白 | `#FFFFFF` | 内容卡、控制面板 |
| 边框 | 雾灰 | `#DDE5EC` | 1 px 分割线和卡片边框 |
| 次要文字 | 灰蓝 | `#6F8295` | 辅助说明、标签、页码 |

### 2.1 用色比例

推荐一页或一个界面的面积比例：

- 白色与冷白：约 80%。
- 墨蓝与正文蓝：约 15%。
- 路径蓝、定位橙和山径绿合计：不超过 5%。

橙色是全套视觉中最稀缺的颜色。只有“知识断点”“当前核心结论”“需要用户注意的异常”可以使用橙色。

## 3. 字体与排版

### 3.1 字体

- 中文：优先使用苹方 / HarmonyOS Sans / 思源黑体。
- 英文与数字：优先使用 SF Pro Display / Inter。
- 数学公式：保持 KaTeX 或类似数学字体。
- 不使用书法字体作为正文。海报中的手写感只属于原始品牌物料，不延伸到产品与 PPT 正文。

### 3.2 字重

- 大标题：Semibold，避免使用过重的 Heavy。
- 正文：Regular。
- 标签和按钮：Medium。
- 同一段落内最多出现两个字重。

### 3.3 PPT 字号建议（16:9）

| 层级 | 建议字号 |
| --- | --- |
| 封面主标题 | 42–60 pt |
| 页面核心结论 | 32–44 pt |
| 二级标题 | 22–28 pt |
| 正文 | 16–20 pt |
| 辅助说明 | 11–14 pt |
| 数据大数字 | 40–64 pt |

标题建议使用紧凑字距，正文行距为字号的 1.4–1.6 倍。每行中文尽量不超过 24 个字。

## 4. 布局系统

### 4.1 基本原则

- 内容遵循左对齐，只有单一结论页可居中。
- 页面四周保留明显安全区，PPT 建议至少 64 px。
- 使用 8 px 基础网格：间距优先取 8、16、24、32、48、64。
- 一页只设置一个视觉焦点，其他内容降低对比度。
- 产品截图不铺满页面，四周保留空间，让截图像一个“产品对象”。

### 4.2 推荐 PPT 页面结构

1. **封面页**：左侧品牌与一句话定位，右侧只放一个代表性图谱画面。
2. **问题页**：一个大问题句 + 1 个橙色关键词，不堆砌行业痛点。
3. **方案页**：用“提问 → 诊断 → 定位 → 学习 → 掌握”的单路径表达。
4. **产品页**：大尺寸界面截图 + 2–3 条短注释。
5. **原理页**：以知识图谱为主体，突出一个逐渐变亮的橙色节点。
6. **结果页**：用墨蓝大数字展示指标，绿色只标记正向结果。
7. **结束页**：复用品牌主张，不添加新信息。

## 5. 图形与组件

### 5.1 Logo / 品牌符号

产品 Logo 使用“上升路径 + 四个节点”的抽象符号：

- 路径和普通节点使用路径蓝。
- 右上角终点使用定位橙。
- 图标放在雾蓝色圆角方形容器中。
- 图标周围需要留出至少图标宽度 25% 的安全空间。

### 5.2 卡片

- 默认使用白色卡片。
- 圆角：14–18 px。
- 边框：`#DDE5EC`，1 px。
- 阴影应非常轻，仅用于区分层级，不制造悬浮感。
- 同一页卡片数量超过 4 个时，应优先用分区或列表替代。

### 5.3 按钮

- 主按钮：路径蓝或墨蓝底，白字。
- 次按钮：白底、雾灰边框、深雾蓝文字。
- 危险操作：白底、浅红边框、红色文字。
- 同一视图只保留一个主按钮。
- 产品按钮推荐胶囊形；PPT 中无需把普通文字标签画成按钮。

### 5.4 知识图谱

| 节点状态 | 颜色 | 视觉行为 |
| --- | --- | --- |
| 普通节点 | 雾灰蓝 `#9AA9B7` | 始终可见，降低强调但不降低到难以阅读 |
| 题目相关 | 路径蓝 `#287ACC` | 蓝色实心节点，可有轻微外环 |
| 疑似薄弱 | 定位橙 `#F0642B` | 随置信度增大尺寸、饱和度、扁平关注面和外环 |
| 已掌握 | 山径绿 `#2FA36B` | 稳定绿色，不使用持续闪烁 |
| 推荐学习 | 柔和靛蓝 `#6F73C9` | 作为次级推荐，不抢夺橙色焦点 |

图谱表现的核心不是“所有节点一起发光”，而是：

1. 所有节点和名称始终可辨认。
2. 诊断开始后出现多个橙色候选。
3. 每轮回答后，置信度最高的候选逐渐更大、更亮。
4. 最终目标节点具有最清晰的橙色外环。
5. 学习通过后，橙色平滑过渡为绿色。

## 6. 动效规范

动效用于解释状态变化，不用于装饰。

| 场景 | 时长 | 缓动建议 |
| --- | --- | --- |
| 页面 / 卡片进入 | 300–450 ms | ease-out |
| 按钮 hover / press | 160–200 ms | ease-out |
| 弹窗出现 | 250–300 ms | cubic-bezier(.2,.8,.2,1) |
| 图谱节点置信度变化 | 1000–1300 ms | smootherstep，起止速度均为 0 |
| 教学步骤切换 | 280–350 ms | ease-out |
| 橙色变绿色 | 500–700 ms | ease-in-out |

动效幅度建议：

- 页面进入仅移动 6–10 px，并伴随透明度变化。
- 按钮 hover 上移不超过 1 px。
- 按钮按下缩放至 98%。
- 图谱节点不要闪烁或使用霓虹阴影；使用连续、平滑的颜色混合、尺寸与外环变化。
- 每轮诊断后，镜头平滑框选全部受关注节点，移动与缩放约 1000 ms。
- 必须兼容“减少动态效果”，此时取消位移和缩放，仅保留必要的颜色状态变化。

### 6.1 PPT 动画建议

- 全套只使用“淡入”“平滑移动”和 Morph/神奇移动。
- 单页动画不超过 3 组。
- 展示诊断过程时，让 2–3 个橙色候选先出现，再让目标节点逐步放大并增强颜色。
- 避免弹跳、旋转、飞入、擦除等强烈转场。

## 7. 产品关键页面表达

### 7.1 登录页

- 左侧为一句大字号品牌主张。
- 右侧为纯白登录表单。
- 不使用插画背景或大面积渐变。
- 可用一条极简节点路径作为功能暗示。

### 7.2 提问与直接解答页

- 输入框是唯一视觉焦点。
- 提交后先展示直接答案，再由用户主动选择是否开始知识诊断。
- 超纲问题使用浅橙提示卡，明确说明“当前知识库暂时无法解答”。
- 提示用户更换问题或补充教材，不自动匹配无关节点。

### 7.3 诊断页

- 右侧每次只展示一道诊断题。
- 左侧图谱持续展示定位收敛过程。
- 橙色亮度代表薄弱置信度，而不是掌握程度。
- 诊断结束后由用户主动选择要学习的节点。

### 7.4 交互学习页

- 分为“概念、直觉、联系、示例、易错点、检测”六步。
- 一次只呈现一个知识重点。
- 每一步提供“没看懂”，连续请求更通俗的解释；第三次后允许退出学习。
- 最终一步才出现检测题。
- 检测未通过时提供“继续学习”和“退出学习”。
- 退出后节点保持橙色；通过后节点变为绿色。
- 学习过程中橙色强调逐步减弱、绿色强调逐步增强；检测失败则平滑退回橙色。

## 8. PPT 截图与标注规范

- 截图使用浅色版本，保持真实比例，不拉伸。
- 建议给截图添加 16–24 px 圆角和非常轻的阴影。
- 标注线使用路径蓝，关键断点标注使用定位橙。
- 一张截图最多标注 3 个位置。
- 标注文案使用短语，例如“逐轮收敛”“断点定位”“分步学习”，不要写完整段落。
- 不在截图上覆盖大面积半透明色块。

## 9. 设计交付检查表

- [ ] 页面是否只有一个最明显的视觉焦点？
- [ ] 橙色是否只用于知识断点或核心强调？
- [ ] 普通节点和标签是否仍清晰可见？
- [ ] 是否保留了足够留白？
- [ ] 是否避免了复杂背景与不必要装饰？
- [ ] 标题、正文、辅助说明是否有明确的三级层级？
- [ ] 动效是否在解释状态，而非单纯吸引注意？
- [ ] PPT 中的图谱颜色是否与产品状态完全一致？
- [ ] 截图是否保持比例并避免过度标注？
- [ ] 即使去掉动画，信息是否仍然完整易懂？
