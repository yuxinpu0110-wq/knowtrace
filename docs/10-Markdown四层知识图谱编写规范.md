# KnowTrace Markdown 四层知识图谱编写规范

## 1. 核心原则

KnowTrace 不再猜测知识关系，也不调用大模型建图。程序将 Markdown 标题直接转换为知识节点，并将标题的上下级关系转换为图谱中的直接父子关系。

| Markdown | 图谱含义 | 示例 |
| --- | --- | --- |
| `#` | 一级母知识点 | 函数 |
| `##` | 二级子知识点 | 初等函数 |
| `###` | 三级孙知识点 | 三角函数 |
| `####` | 四级末端知识点 | 正弦函数 |

最多支持四层。每一个标题都必须表示一个真实知识点，而不是“第一篇”“第一章”“基础部分”等排版目录。

## 2. 父子关系规则

- `##` 自动连接到它之前最近的 `#`。
- `###` 自动连接到它之前最近的 `##`。
- `####` 自动连接到它之前最近的 `###`。
- 只建立直接父子边，不会把祖先节点直接连接到所有后代。
- 多个同级标题表示同一个母知识点下的多个并列子知识点。
- 多个一级标题会生成多个独立的知识树。如果希望得到一张连通图，建议整份文件只设置一个一级母知识点。

## 3. 必须遵守的格式

1. 第一个知识点必须使用 `#`。
2. 标题不能跳级。例如，`#` 后不能直接出现 `###`，必须先有 `##`。
3. 不得使用 `#####` 或更深层标题。
4. `#` 与知识点名称之间必须有一个空格。
5. 同一个母知识点下的子知识点名称应尽量唯一。
6. 文档名称不要占用标题层级。可以用普通文本、粗体或注释书写文档名称。

错误示例：

```markdown
# 导数
### 隐函数求导
```

这里从一级直接跳到了三级，程序会明确报错。

## 4. 推荐模板

下面的内容可以直接复制后修改：

```markdown
**教材名称：微积分知识体系**

# 函数

函数描述输入与输出之间的对应关系。

## 初等函数

由基本函数经过有限次运算与复合得到的函数。

### 三角函数

研究角度与边长比例之间的函数关系。

#### 正弦函数

正弦函数记作 $y=\sin x$，定义域为 $\mathbb{R}$。

#### 余弦函数

余弦函数记作 $y=\cos x$，定义域为 $\mathbb{R}$。

### 指数函数

指数函数的一般形式为 $y=a^x$，其中 $a>0$ 且 $a\ne1$。

## 复合函数

复合函数由两个或多个函数嵌套构成。

### 复合函数求导

复合函数求导使用链式法则。
```

上述模板会生成以下关系：

```text
函数
├── 初等函数
│   ├── 三角函数
│   │   ├── 正弦函数
│   │   └── 余弦函数
│   └── 指数函数
└── 复合函数
    └── 复合函数求导
```

## 5. 正文内容如何使用

标题下面、下一个标题之前的正文会成为该节点的摘要来源。建议正文包含：

- 一到三句定义或直观解释；
- 关键公式，使用 LaTeX；
- 必要的适用条件；
- 一个简短例子。

普通段落、列表、公式和代码块不会单独生成节点。代码围栏中的 `#` 也不会被识别为标题。

## 6. 编号规则

可以给标题添加数字编号：

```markdown
# 1 函数
## 1.1 初等函数
### 1.1.1 三角函数
```

生成节点时，开头的数字编号会被自动移除，节点名称分别显示为“函数”“初等函数”“三角函数”。编号只用于帮助编写者检查层级。

## 7. 建议的知识粒度

- 一级知识点：完整知识域，例如“函数”“极限”“导数”。
- 二级知识点：该知识域中的主要概念族或方法族。
- 三级知识点：可以单独学习和诊断的具体概念。
- 四级知识点：三级知识点下需要进一步拆分的定义、性质或方法。

不要为了视觉上增加节点而过度拆分。一段内容如果不能独立提问、讲解或检测，通常不需要成为单独节点。

## 8. 生成前检查清单

- 第一个标题是否为 `#`；
- 是否只使用 `#` 到 `####`；
- 是否不存在标题跳级；
- 每个标题是否都是真实知识点；
- 同一母知识点下是否存在重名子节点；
- 需要连通图时是否只有一个一级母知识点；
- 每个末端知识点是否有足够正文供后续问答与学习使用。
